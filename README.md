# Dungeon

Одностраничный лендинг на HTML, CSS и JavaScript. Одна из первых учебных вёрсток (2023).

## Стек

- HTML5, CSS3
- JavaScript (`js/app.js`)
- Свои шрифты и изображения

## Запуск

Сборка не нужна: откройте `index.html` в браузере.

```
Dungeon/
├── index.html
├── css/main.css
├── js/app.js
├── fonts/
├── img/
└── libs/
```
